To build and compile fastdist:
> In CLion make sure CMake runs and then Build it
>>> This will produce the .pyd file under cmake-build-debug
> In PyCharm run "python3 setup.py bdist_wheel"
> NOTE: This is currently ONLY working with Python3.14
>>> This will create the wheel file
> To add to the test.py project open the python venv(3.14) with ".\.venv314\Scripts\activate" and run
>> "pip install .\dist\fastdist-0.0.1-cp314-cp314-win_amd64.whl --force-reinstall"
